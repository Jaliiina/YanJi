# 使用研迹

先创建项目并填写名称，可备注研究目标或数据来源。进入项目后，“项目概览”会告诉你下一步；名称与备注可以编辑。

在“项目文件”添加数据，先核对实际预览。CSV/TSV、Excel 和平面 JSON 记录表都可导入。表头不是第一行、分隔符或编码不同时，展开读取方式调整再预览；一个工作簿可以登记多个工作表。

文件页默认展示内容。“补充背景或解释某一列”为选填，适合说明单位、特殊编码或记录对象；清楚的列名不必重复填写。模型整理的说明需查看后应用并保存。

到“开始分析”选择本次要用的文件，描述问题或直接选择工具。文件保存在项目里，不等于每次任务都要全部使用。同类文件不会彼此覆盖；有歧义时系统会要求明确输入，不自行拼接。

选择比较任务时，页面会从选定文件读取实际列和组值，请选出两组并说明是否有重复或配对观测。此设置只属于本次任务，文件页无需预先配置研究设计。

认可方案后，在“研究成果”查看结果与图表、展开依据并下载完整结果。需要写作时在同一位置切换到“论文与报告”，按需整理、编辑和导出。AI 起草和引用绑定仍需人工核查。
